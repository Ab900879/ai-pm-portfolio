# 标题：AI胡说八道？给它配个随身小抄

你有没有发现，AI有时候会一本正经地胡说八道？不是它笨，是它只靠“记忆”答题，没带参考资料。

有个办法能治——相当于考试前给它塞了张小抄。它先翻资料，再开口回答，胡编的概率就低多了。具体怎么翻？把你的文档拆成小段（像把一整本书剪成便利贴），给每张便利贴编个“指纹”（方便快速找到相似内容），存进一个“智能档案柜”。你提问时，它先从柜子里抽出最相关的几张便利贴，贴在问题旁边，再一起交给AI组织答案。

好处是：不用重新训练AI（不用让它回炉重造），资料更新了只需换便利贴，省钱又省时。

今天就能做的小动作：挑一篇你熟悉的文章，试着把它剪成5段便利贴大小的话，感受一下“切分”是怎么回事。
